プライバシーポリシー

TouchRotator は、お客様の個人情報を収集しません。以下はその詳細です。

アプリが集めないもの

  • お名前、メールアドレスなどの個人情報
  • タッチの座標、操作の内容、使用状況の統計
  • 画面の内容、開いているアプリやウィンドウの中身

タッチ座標の補正は、すべてお使いの Mac の中だけで行われます。外部に送信されることはありません。

アプリが通信するとき

本アプリが外部と通信するのは、次の 1 つだけです。

  • 更新の確認 — GitHub の公開 API（api.github.com）に接続し、新しいバージョンが出ているかを確認します。送信するのは通常の HTTP リクエストのみで、お客様を識別する情報は含みません。設定画面でオフにできます。

Mac に保存されるもの

  • 設定 — 回転方向、対象ディスプレイ、補正値など。macOS の UserDefaults に保存されます
  • ライセンスキー — macOS のキーチェーンに保存されます

どちらも、お使いの Mac の中にとどまります。

購入したとき

決済は販売代行会社が処理します。カード番号などの決済情報は同社が扱い、当方は受け取りません。同社のプライバシーポリシーが適用されます。当方が知るのは、ライセンスの発行に必要な範囲のみです。

このウェブサイト

本サイトは GitHub Pages でホストされています。アクセスに伴い GitHub がログ（IP アドレス等）を取得します。当方は解析ツールや広告、Cookie を使用していません。
