隐私政策

TouchRotator 不收集任何个人信息。以下是具体说明。

本应用不会收集

  • 姓名、电子邮件地址等个人信息
  • 触摸坐标、操作内容与使用统计
  • 屏幕内容，以及您打开的应用与窗口中的内容

触摸坐标的校正全部在您的 Mac 本机完成，不会传送到外部。

本应用的网络通信

本应用与外部通信的情形只有一种：

  • 检查更新 — 连接 GitHub 的公开 API（api.github.com），确认是否有新版本。发送的仅是普通 HTTP 请求，不包含可识别您身份的信息，并且可以在设置中关闭。

保存在 Mac 上的内容

  • 设置 — 旋转方向、校正对象显示器、校正数值等，保存在 macOS 的 UserDefaults 中
  • 许可证密钥 — 保存在 macOS 钥匙串中

两者都只保留在您的 Mac 上。

购买时

付款由销售代理处理。银行卡等支付信息由该公司处理，我们不会收到；该交易适用其隐私政策。我们仅获知发放许可证所必需的信息。

本网站

本网站托管于 GitHub Pages，GitHub 会记录访问日志（含 IP 地址）。我们不使用分析工具、广告或自有 Cookie。
