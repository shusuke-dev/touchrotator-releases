让竖置的触摸屏
在 Mac 上正常工作。

把外接触摸屏旋转 90° 后，手指触碰的位置与指针的位置就会错开。TouchRotator 负责校正坐标，同时把显示器设置与窗口布局放进菜单栏。

三项功能

1. 触摸校正 —— 触碰的位置，就是响应的位置

把面板旋转 90° 后，macOS 仍按旋转前的方向接收坐标。指针会横向跳开，或与手指的方向相反，原因就在这里。TouchRotator 直接读取面板的 USB 信号来校正坐标，因此不影响触控板与鼠标的操作。

设置 → 触摸校正，选择目标显示器，执行一次点按自动检测。之后用 ⌥⌘R 开关。

2. 显示器设置 —— 不打开系统设置，一次点击完成

分辨率、亮度、镜像、旋转，都能在菜单栏的弹窗里更改。每台显示器一张卡片，接几台就有几张。

点击菜单栏图标 → 点显示器名称即可展开卡片。

3. 窗口布局 —— 重新接上，也回到原来的位置

拔掉显示器后，原本在上面的窗口会被挤到内建显示器，重新接上也不会回去。TouchRotator 会记住布局，在显示器接回来时把窗口恢复到原来的位置和大小。

摆放好之后，点一次记住当前布局。之后会自动恢复，也可以随时用恢复布局调出。

如果你遇到这些情况

点按的位置与反应的位置不一致

外接触摸屏竖置时最常见的症状。

指针与手指的方向相反

向上变成向下，向右变成向左。面板的方向尚未被学习。

触摸落到了内建显示器上

没有碰过的屏幕却有反应。选择校正的目标显示器即可解决。

每次重新连接，窗口都乱掉

不必再一个个把窗口摆回原处。
