TouchRotator
日本語English简体中文

让竖置的触摸屏
在 Mac 上正常工作。

把外接触摸屏旋转 90° 后，手指触碰的位置与指针的位置就会错开。TouchRotator 负责校正坐标，同时把显示器设置与窗口布局放进菜单栏。

免费试用 14 天 查看价格

macOS 13 或更高版本 · 已使用 Apple Developer ID 签名并通过 Apple 公证

三项功能

触摸校正

校正竖置面板的坐标。直接读取面板的 USB 信号，因此不会影响触控板和鼠标的操作。

显示器设置

分辨率、亮度、镜像与旋转，在菜单栏中一键完成，无需打开系统设置。

窗口布局

记住窗口的位置与大小，重新连接显示器后恢复原状。

如果你遇到这些情况

  • 把外接触摸屏竖起来后，点按的位置与实际反应的位置不一致
  • 指针的移动方向与手指相反
  • 触摸输入跑到了内建显示器上
  • 每次重新连接显示器，窗口位置都乱掉
